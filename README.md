# Luxe Laser by Naima

قالب متجر عربي RTL متخصص في أجهزة إزالة الشعر IPL والليزر المنزلي وملحقات العناية.

## الملفات
- `index.html` — الهيكل والمحتوى.
- `style.css` — التصميم المتجاوب والتأثيرات البصرية.
- `script.js` — كتالوج الأجهزة، السلة، والطلب عبر البريد الإلكتروني.
- `assets/logo.png` — الشعار.
- `assets/ipl-device.jpeg` — صورة جهاز إزالة الشعر المرفقة.

## تعديل المعلومات بسرعة
افتحي `script.js` وعدّلي القسم الموجود في البداية:

```js
const STORE = {
  name: 'اسم المتجر',
  whatsapp: '213550000000',
  currency: 'دج',
  products: [ ... ]
};
```

لإضافة منتج، انسخي أحد العناصر داخل `products` وغيّري `id` و`name` و`category` و`price` و`description` و`colors`.

### إضافة صورة لمنتج جديد
1. ضعي الصورة داخل مجلد `assets`.
2. أضيفي المسار داخل المنتج، مثل:

```js
image: 'assets/my-device.jpg'
```

إذا لم تضعي `image` سيظهر رمز المنتج الموجود في `emoji` بدلاً من الصورة.

## النشر على GitHub Pages
1. أنشئي مستودعاً جديداً على GitHub.
2. ارفعي الملفات كما هي مع مجلد `assets`.
3. من Settings → Pages اختاري الفرع `main` والمجلد `/root`.
4. احفظي وانتظري ظهور رابط الموقع.

لا يحتاج الموقع إلى خادم أو قاعدة بيانات، ويعمل على الهاتف والكمبيوتر. الطلبات تُرسل برسالة واتساب جاهزة، مع تأكيد السعر والتوصيل يدوياً.

## بيانات العميل والتواصل
من داخل السلة توجد خانات للاسم الكامل، البريد الإلكتروني، رقم الهاتف، الولاية/المدينة، العنوان، والملاحظات. بعد تعبئتها والضغط على زر الإرسال، يرسل الموقع الطلب مباشرة دون فتح تطبيق البريد. يستخدم القالب خدمة FormSubmit المجانية؛ غيّري البريد في `STORE.email` و`STORE.formEndpoint`، ثم وافقي على رسالة التفعيل الأولى التي تصل إلى بريدك.
